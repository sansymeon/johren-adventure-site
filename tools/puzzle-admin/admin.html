保存と公開

「既定にする」は site/data/puzzle/ に保存します。公開は次のコマンドです。Cursor は要りません。

git add site/data/puzzle site/media/puzzles
git commit -m "Update the default puzzle image"
git push
netlify deploy --prod --no-build --dir=site

netlify deploy はリポジトリの外から --dir=site で実行します。
